CNMD ENGINEERING — LORRY & TRAILER REPAIR WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox or another modern browser.
3. For editing, open this folder in Visual Studio Code. The Live Server extension is optional.
